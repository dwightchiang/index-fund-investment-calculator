# 手工数据目录

这里有两个入口，按「省事程度」排：

## 方案 A（推荐）：导出的表直接喂给 `import` → `percentiles.csv`

同花顺 / iFinD 的指数页「简况 → 指数分析 → 估值分析」本来就给出 PE/PB/PS/PCF 的
1/3/5/10 年分位。既然分位是人家算好的，就不必再自己拿 10 年原始序列重算。

**正常用法是导出 + 一条命令**，不用手抄：

```powershell
python -m dca import "D:\下载\估值分析.xlsx"
```

程序会认表头、认两行合并表头、认 0-1 量纲，然后把 `percentiles.csv` 写好并自动刷新快照。
单指数导出用 `--code 000300`；表里没有日期列时加 `--date 2026-10-31`。

如果手机上只能看、不能导出，用 `set` 一行敲一个指标即可：

```powershell
python -m dca set 沪深300 --ps 4.35
python -m dca set 000905 --ps 6.4 --date 2026-10-30
```

生成的 `percentiles.csv` 长这样（`#` 开头是注释，每个指数取最新日期那一行）：

```
date,code,pe_pct,pb_pct,ps_pct,pcf_pct
2026-10-23,000300,51.4,26.8,45.2,60.1
2026-10-23,000905,70.5,68.0,55.3,48.2
```

- `date` 填**分位数据对应的日期**（同花顺显示的是上一交易日）；
- 只填你有把握的列，空着的列程序会自动回退到蛋卷自算；
- 也可以手工编辑这个文件，格式一样就行；
- 示例见 `percentiles.example.csv`。

这套做法不依赖任何历史数据源，也不受 iFinD 免费版「只能取 5 年」的限制。

## 方案 B：填原始序列 → `<代码>_<指标>.csv`

如果你有某个指标的完整日频序列（比如自己买了数据），按下面格式放进来，
程序会用它自己算分位。

免费公开接口基本不给指数的**市销率（PS）**，所以这里留了一个手工/半自动入口：
把任何一个指标的日频序列放进 `data/manual/<指数代码>_<指标>.csv`，程序会自动使用它。

## 文件命名

| 文件 | 含义 |
|---|---|
| `data/manual/000300_ps.csv` | 沪深300 的市销率序列 |
| `data/manual/000905_ps.csv` | 中证500 的市销率序列 |

## 文件格式

```csv
date,value
2024-01-02,1.1523
2024-01-03,1.1488
...
```

- 表头可以是 `date,value` / `日期,数值` / `日期,市销率`，程序取前两列；
- 日期支持 `2024-01-02` 或 `20240102`；
- 编码 UTF-8 / GBK 都行；
- 序列越长越好，至少覆盖 10 年才有真实意义；不足时程序会按现有样本算，并在 `update` 里打印样本区间。

## 三种拿到 PS 的办法

1. **同花顺客户端导出（零成本，半自动）**
   客户端里打开指数估值表 → 右键导出 Excel → 另存为 `日期,市销率` 两列 CSV → 覆盖对应文件。
   缺点：每天要手动导出一次，历史数据需要一次性补全。

2. **付费数据接口（全自动，推荐）**
   理杏仁 OpenAPI、同花顺 iFinD、Wind、Choice 都有指数 PE/PB/PS 的完整日频历史，
   在 `dca/sources/` 下仿照 `danjuan.py` 写一个 30 行的适配器，然后在 `cli.py`
   的 `_metric_series()` 里加一个分支即可。

3. **自己算（工程量大，不推荐）**
   指数 PS = Σ成分股总市值 / Σ成分股营业收入(TTM)，需要历史成分股名单 + 历史股本 + 季度财报，
   个人维护成本高。

> 拿不到 PS 时，把 `config.toml` 里的 `metrics` 改成 `["pe", "pb"]` 即可先用两个指标跑，
> 规则不变，只是少一个维度。
